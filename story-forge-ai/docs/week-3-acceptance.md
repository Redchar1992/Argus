# 第三周验收清单

第三周把第二周批准的人物和大纲推进为可持续创作的单章闭环：

```text
批准大纲
  → 生成并确认 3～6 场景计划
  → 流式生成单章正文
  → 机械校验 + 六维审核
  → 低于 82 分时最多自动修订两次
  → 人工编辑 / 局部 AI 改写
  → 版本对比、恢复与批准
  → 更新摘要、事实、关系、剧情线和伏笔
  → 下一章读取已确认记忆
```

## 一键验收

```bash
# AI Service：章节子图、流事件、审核修订和记忆提取
cd story-forge-ai/ai-service
pytest
ruff check .
pip check

# Backend：章节版本、SSE、幂等、并发与长期记忆
cd ../backend
mvn -B verify

# Frontend：流式编辑、防覆盖、改写提案与版本操作
cd ../frontend
npm test -- --run
npm run build

# 完整 Docker 链路
cd ..
python3 deploy/smoke_chapter_workflow.py
```

## 章节计划

- [ ] 只能为当前用户已批准大纲下的故事创建章节。
- [ ] 每个计划包含 3～6 个连续编号的场景。
- [ ] 每个场景都有地点、角色、目标、阻力、可见冲突和离场钩子。
- [ ] 场景角色都来自批准的人物卡，未知角色会被拒绝。
- [ ] 计划批准前不能生成正文；批准后修改计划需要显式创建新任务。

## 正文、审核与自动修订

- [ ] 正文 Token 通过 SSE 按严格递增序号实时展示。
- [ ] 页面刷新或 SSE 重连后通过 `Last-Event-ID` 补齐事件，不重复拼接正文。
- [ ] 初稿与每次 AI 修订都创建不可变版本，不覆盖旧内容。
- [ ] 代码检查正文为空、长度、段落和重复；确定性错误不交给模型猜测。
- [ ] 六维分数由应用代码按各维上限汇总为 100 分。
- [ ] 总分低于 82 或存在致命问题时自动修订，最多两次。
- [ ] 两次后仍不合格也进入人工审核，不形成无限循环。

## 编辑器与局部改写

- [ ] 用户编辑使用 `baseVersionId` 乐观并发保存，并生成 `USER_EDIT` 版本。
- [ ] 自动保存不会覆盖更新的服务端版本，也不会被迟到的 Token 覆盖。
- [ ] 改写请求包含精确偏移、原文和 SHA-256；结果只保存为提案。
- [ ] 页面同时展示原文、建议文本和原因，用户可接受、拒绝或重新生成。
- [ ] 接受前再次校验版本、偏移和 Hash；过期提案返回冲突且不修改正文。
- [ ] 版本历史可查看、对比；批准前恢复会创建新版本，批准后仅可查看，且不伪装支持长期记忆回滚。

## 长文本记忆

- [ ] 批准章节后保存章节摘要，并且下一章只读取最近三章摘要和结构化事实。
- [ ] Canon Fact、人物关系、剧情线和伏笔按稳定业务键 Upsert。
- [ ] `locked=true` 的事实不能被 Memory Agent 覆盖，只记录连续性警告。
- [ ] 已解决剧情线和已回收伏笔保留历史状态，不被重新创建为未解决。
- [ ] 正式正文和长期记忆保存到 MySQL，不以 Redis 事件作为最终存储。

## 异步、幂等与恢复

- [ ] 命令写入 `story:chapter:commands`，事件写入 `story:chapter:events`。
- [ ] Worker 完成事件发布和幂等结果记录后才 `XACK`。
- [ ] Pending 命令和事件可被重新领取；重复命令不会重复调用模型或创建版本。
- [ ] SSE 事件先事务持久化，再推送浏览器和确认 Redis 事件。
- [ ] 章节任务失败保留错误码、节点和重试入口。
- [ ] 正式章节在服务重启后仍可查看；本地暂停线程使用持久 Checkpointer。

## 固定连续性回归

- [ ] 第 1 章角色受伤后，第 2 章不会无解释恢复。
- [ ] 仅读者知道的秘密不会被未知情角色直接用于行动。
- [ ] 已死亡角色只能以回忆、录像或合理解释再次出现。
- [ ] 已转移的关键物品不会无解释回到原持有人手中。
- [ ] 用户在 AI 生成期间保存新版本时，迟到结果不会覆盖该版本。
- [ ] 同一 `idempotencyKey` 重放不会产生重复正文版本或重复记忆。

## 本周明确不做

- 一键生成全书或自动发布
- 复杂向量知识库与文风微调
- 多人协作编辑
- ChatGPT OAuth、MCP 插件和投稿平台集成
- 支付、额度扣费和第四周的作品导出/成本控制界面
